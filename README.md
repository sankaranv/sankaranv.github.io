# Personal Website

## Local preview

```
brew install ruby imagemagick   # once
bin/preview                     # http://localhost:4000, live reload
```

Restart `bin/preview` after editing `_config.yml`.

## Citation counts

"cited by N" links read `_data/citations.yml`. The deploy workflow refreshes it from Google Scholar on every push and every Monday, and commits it when the counts change. If Scholar blocks the CI runner, the last saved counts stay up. To refresh by hand, run `bin/update-citations` and commit the file.

## Kolam

The faint kolam in the side margins is `assets/img/kolam-tile.svg`, generated by `bin/kolam.py`. Edit the pattern constants in the script and rerun it:

```
python3 bin/kolam.py
```
